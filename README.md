A lightweight expression language designed for embedding in Go applications, focusing on expressions, simple functions, and seamless Go integration.

## Features

- 🚀 **Lightweight**: Minimal overhead, designed for embedding
- 🔧 **Type Safe**: Static typing with type inference support
- 🏗️ **Struct Support**: Define structs with methods
- 📦 **Container Types**: Built-in List, Map, and Set support
- 🔍 **Lambda Expressions**: Functional programming support
- ⚡ **Fast Parsing**: ANTLR4-based parser for high performance
